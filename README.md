# 🩸 BloodLagbe – Blood Donation Management System

**BloodLagbe** is a Java-based application designed to connect blood donors with patients in need.
The system helps manage donor information, blood requests, and availability efficiently.

---

## 📌 About The Project

Blood donation is critical for saving lives during emergencies, surgeries, and medical treatments.
**BloodLagbe** aims to simplify this process by creating a centralized system where:

* Donors can register and provide their details
* Patients can request blood easily
* Admin can manage all records efficiently

💡 This project demonstrates real-world problem solving using software development.

---

## 🎯 Objectives

* 🩸 Connect blood donors and recipients
* 📊 Maintain donor and blood records
* ⚡ Provide quick access to blood availability
* 🧠 Improve efficiency of manual systems

---

## ✨ Features

* 👤 Donor Registration & Management
* 🔍 Search donor by blood group
* 🩺 Blood request system
* 📋 Record management (donor & patient)
* 🖥️ User-friendly interface
